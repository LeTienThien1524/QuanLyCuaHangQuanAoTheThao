# Quản Lý Cửa Hàng Quần Áo Thể Thao

Ứng dụng quản lý cửa hàng quần áo thể thao được phát triển bằng **C# WinForms**, **.NET 8** và **SQL Server**.

## Chức năng chính

* Đăng nhập và phân quyền người dùng
* Quản lý sản phẩm
* Quản lý danh mục sản phẩm
* Quản lý khách hàng
* Quản lý nhà cung cấp
* Quản lý kho
* Quản lý nhập hàng
* Quản lý đơn hàng
* Thống kê doanh thu
* Xuất báo cáo và hóa đơn PDF
* Dashboard thống kê trực quan

## Công nghệ sử dụng

* C#
* WinForms
* .NET 8
* Entity Framework Core
* SQL Server

## Cài đặt và chạy dự án

### 1. Clone repository

```bash
git clone https://github.com/LeTienThien1524/QuanLyCuaHangQuanAoTheThao.git
```

### 2. Cấu hình cơ sở dữ liệu

Cập nhật chuỗi kết nối trong file `appsettings.json` hoặc `AppDbContext`.

### 3. Chạy dự án

Mở file solution:

```text
DoAn1_QuanLyCuaHangQuanAoTheThao.sln
```

sau đó chạy bằng Visual Studio.

## Một số hình ảnh của dự án

* Màn hình đăng nhập
* Dashboard
* Quản lý sản phẩm
* Quản lý kho
* Thống kê doanh thu
